SYSTEM DESIGN / AQUAVAULT OS

Platform architecture

Functional decomposition of the self-hosted Kubernetes environment.

PLATFORM COMPONENTS LOGICAL LAYERS
01 / Network edge

Cloudflare Tunnel routes external requests to private services.

02 / Identity

Authentik provides centralized identity and OIDC integration.

03 / Orchestration

k3s schedules container workloads on a single Raspberry Pi node.

04 / Delivery

Argo CD reconciles declarative GitOps application definitions.

05 / Application layer

WorkOS and Nextcloud provide workspace and file functionality.

06 / Data

PostgreSQL and persistent volumes store stateful application data.

07 / Recovery

Encrypted Image Vault backups support restoration and GitOps recovery.

08 / Source control

Private and public GitHub repositories host code and infrastructure configuration.

DESIGN CONSTRAINTS

Engineering decisions

Designed as an operational homelab, not a simulated cloud dashboard. The architecture emphasizes reproducibility, recoverability and identity integration within limited hardware resources.
