Side Quest CRM

The problem: enquiries, opportunities and follow-ups become scattered across tools. Side Quest CRM connects discovery, transparent fit scoring, proposal drafts and pipeline tracking in one workflow.

Try the public demo ↗View source ↗

The public demo uses fictional records and resets on reload. Real enquiries and client notes stay in the private workspace.

Blueprint & evidence

Stack rationale: JavaScript powers the interface, Cloudflare Workers provides the API, private R2 storage keeps records separate from public source, and GitHub Actions runs background workflows. Optional Firecrawl adds public web discovery.

Evidence: try the fictional-data demo and inspect the public source. No measured revenue or productivity improvement is claimed.

Technical philosophy

Context before code.
Always.

Every stack has a cost beyond its invoice: operating effort, failure modes, integration work and the difficulty of leaving it later.

I start with data scale, response-time needs, compute budgets and the team’s ability to maintain the system. Then I compare the trade-offs and choose a practical path, with assumptions made explicit.
